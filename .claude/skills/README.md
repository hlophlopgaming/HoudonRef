# Agent skills

Skills under this folder (except any added by this project later) come from
[mattpocock/skills](https://github.com/mattpocock/skills), commit 5863806,
under the MIT licence (see `LICENSE-mattpocock-skills`). They are copied
unmodified apart from removing the `agents/` folders, which only configure
other coding agents.

Repository configuration for these skills lives in `docs/agents/` and the
"Agent skills" section of `CLAUDE.md`.
