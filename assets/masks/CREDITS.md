# Light masks

`kenney/` holds *Light Masks* 1.0 by Kenney ([kenney.nl](https://www.kenney.nl)),
the "Default" variant (white lets the light through), all 152 files exactly as
distributed. Licence: [CC0](http://creativecommons.org/publicdomain/zero/1.0/),
