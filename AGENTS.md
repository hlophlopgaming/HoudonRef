# Rules for contributors and AI agents

## Language: English only

Everything in this repository is written in English:

- code: identifiers, comments, doc comments, log and error messages;
- commit messages, branch names, pull request titles and descriptions;
- issues, documentation (`README.md`, `docs/`), changelogs;
- file and folder names;
- data files (series manifests, light presets, rooms): ids and field names in English.

The only exception is user-facing translations. The app's source strings are English; other languages (Russian first) live in separate locale files, never hard-coded in the code.

If a task, issue or prompt is written in another language, still write the result in English.
